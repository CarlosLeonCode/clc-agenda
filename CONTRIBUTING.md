# Contributing to WA Contact Extractor Pro

¡Gracias por tu interés en contribuir! / Thanks for your interest in contributing!

## Cómo contribuir (How to contribute)

1. **Fork** el repositorio.
2. Cloná tu fork localmente: `git clone https://github.com/TU_USUARIO/wasup_contact_extractor_clc.git`
3. Creá una rama (branch) para tu feature o fix: `git checkout -b mi-nueva-feature`
4. Realizá los cambios en el código.
5. Ejecutá los tests para asegurarte de que todo funciona: `npm test`
6. Commiteá tus cambios usando [Conventional Commits](https://www.conventionalcommits.org/): `git commit -m "feat: agregada nueva exportación"`
7. Pusheá la rama a tu fork: `git push origin mi-nueva-feature`
8. Abrí un **Pull Request** hacia la rama `main` del repositorio original.

## Entorno de Desarrollo (Development Environment)

Para probar la extensión localmente mientras desarrollás:
1. Abrí Chrome (o Brave/Edge) y andá a `chrome://extensions/`.
2. Activá el "Modo de desarrollador".
3. Hacé clic en "Cargar descomprimida" y seleccioná la carpeta del proyecto.
4. Cualquier cambio en `popup/` o `content/` va a requerir que refresques la extensión desde la página de extensiones y luego recargues WhatsApp Web.

¡Cualquier mejora es bienvenida! No dudes en abrir un Issue si tenés dudas o encontraste un bug.
